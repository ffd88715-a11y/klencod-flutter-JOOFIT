# JOOFIT PRO v4.0 — النظام الذكي المتكامل للجيم والمتابعة الشخصية 🏋️‍♂️🔥

**تطوير: JOO (YOSSEF JOO) — للتواصل واتساب: `01029892573`**

تطبيق **JOOFIT PRO v4.0** هو النظام الذكي الشامل لإدارة التمرين، تنظيم الجداول الأسبوعية، تتبع الأرقام القياسية (`PRs`)، قياسات الجسم والـ `InBody`، التغذية المصرية، ومؤقتات الجيم الاحترافية باللهجة المصرية وبتصميم **Dark Matte Eye-Comfort** المريح للعين بدون أي ألوان نيون مزعجة.

## أبرز التحديثات والميزات في الإصدار v4.0.0+4:
- **حفظ مستمر لجلسة التمرين والمؤقتات في الخلفية**: حساب الوقت الفعلي المتبقي لمؤقت الراحة ووقت التمرين حتى عند قفل الشاشة أو التنقل بين التطبيقات، مع ميزة منع قفل الشاشة تلقائياً وقت التمرين (`Keep Screen Awake`).
- **تتبع الأرقام القياسية (`Personal Records - PRs 🏆`) وأنواع المجموعات**: تحديد نوع كل مجموعة (`عادي`، `تسخين W`، `دروب سيت D`، `لحد الفشل F`)، مع رصد تلقائي لأعلى وزن (`PR`)، وزر التدرج الذكي في الأوزان (`+2.5 كجم`)، وتعديل أو إعادة ترتيب التمارين داخل اليوم.
- **7 أنظمة تدريب احترافية جاهزة ومفصلة**: تشمل `Push Pull Legs (6 أيام)`، `Arnold Split (6 أيام)`، `Upper / Lower الحقيقي (4 أيام)`، `Bro Split المصري (5 أيام)`، `Full Body (3 أيام)`، ونظام `التنشيف وحرق الدهون HIIT`.
- **دليل أكل الجيم المصري السريع وحاسبة التغذية**: إضافة سريعة لأشهر وجبات الجيم في مصر (صدور فراخ، بيض، جبنة قريش، تونة، فول، شوفان، رز، بطاطا، واي بروتين) بحساب تلقائي للبروتين والسعرات.
- **متتبع قياسات الجسم والـ InBody الذكي**: تسجيل مقاسات الذراع، الصدر، الوسط، الأكتاف، الفخذ، والرقبة مع حساب تلقائي لنسبة الدهون في الجسم (`Body Fat %`) والكتلة العضلية الصافية (`Lean Body Mass`).
- **أدوات الجيم الاحترافية المطورة**:
  - **حاسبة طارات البار المرئية**: رسم توضيحي للبار والطارات بالألوان الأولمبية مع اختيار وزن البار (`20 / 15 / 10 / 0 كجم`).
  - **حاسبة مجاميع التسخين الذكية (Warm-up Sets)** قبل الأوزان الثقيلة.
  - **حاسبة تحويل أوزان البار إلى دمبل والعكس** وحاسبة `1RM`.
  - **موسوعة التمارين المصرية الموسعة** مع نصائح الأداء والأخطاء الشائعة وإمكانية إضافة تمارين مخصصة.
- **شهادة إتمام التمرينة والنسخ الاحتياطي**: ملخص تفصيلي بعد كل تمرينة قابل للمشاركة على واتساب، ونظام نسخ احتياطي واستعادة كامل للبيانات (`JSON Backup & Restore`).
